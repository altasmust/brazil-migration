KAPSAM
Web sitesi, admin, müşteri, danışman ve avukat panelleri; KYC entegrasyon kodları; görseller; sunucu/API kodları; veritabanı şeması ve SQL migration dosyaları; testler; proje ayarları ve bağımlılık listeleri eksiksiz olarak kaynak deposundan alınmıştır.

ÇALIŞTIRMA
Node.js >=22.13.0 gerekir. Proje klasöründe:
  npm ci
  npm run dev
Derleme:

Bu proje Vinext / Cloudflare Worker, D1 ve R2 altyapısı kullanır. Farklı bir sunucuya taşırken kimlik doğrulama, DB ve dosya depolama bağlantıları ayrıca yapılandırılmalıdır. Kaynakların açılması canlı müşteri verilerini otomatik taşımaz.
